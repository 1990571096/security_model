# 系统范围说明

## 目标系统

系统重构目标是将当前比赛项目改造为“面向数据清洗的安全模型训练系统”。系统以图像训练数据的后门中毒风险检测与清洗为核心，当前实现和答辩展示只开放 LDD 训练前数据清洗，后续再扩展其他算法和安全训练能力。

## 核心流程

1. 数据导入：上传图像训练数据集，完成元信息登记、解析、状态管理。
2. 算法配置：登记 LDD 算法，维护参数 schema 和默认参数。
3. 训练前防御：执行 LDD 中毒样本检测、风险评分、干净子集筛选，输出清洗后数据集和清洗报告。
4. 结果导出：依据 LDD 输出的保留样本索引重建并下载清洗子集。
5. 报告生成：输出包含 LDD 参数快照、清洗指标、失败信息和产物信息的实验报告。
6. 扩展预留：为后续训练中、训练后和对比算法保留统一执行器接口，但不纳入当前展示主流程。

## 当前优先级

- P0：数据集、LDD 算法、训练前防御任务、任务进度、实验报告和清洗子集下载。
- P1：LDD 参数校验、执行日志、正式实验指标和安全模型训练衔接。
- P2：训练中防御、训练后防御、多算法组合。
- P3：系统运维监控、代码生成、第三方工具。

## 非目标范围

以下能力不属于论文系统主线，应从菜单、接口依赖和数据库初始化中逐步裁剪：

- 支付宝支付。
- 邮件发送工具。
- S3/对象存储管理控制台。
- 远程部署、服务器管理、数据库执行器。
- ELADMIN 代码生成器。
- 示例页、嵌套路由演示页、外部文档入口。
- 面向通用后台的访问统计示例看板。

## 论文目标映射

开题报告中的“面向数据清洗的安全模型训练系统设计与实现”映射到平台模块如下：

- 数据上传模块：`Dataset`。
- 模型上传模块：`Model`。
- 算法上传模块：`Algorithm`、`Hyper`。
- 数据清洗模块：`PreDefense`。
- 安全模型训练模块：后续新增 `TrainingJob` 或重构 `DuringDefense`。
- 评估报告生成模块：后续新增 `DefenseReport`，短期可承载在各任务 result JSON 字段中。

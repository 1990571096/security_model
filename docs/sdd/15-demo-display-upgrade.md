# 防御演示系统全页面展示升级记录

## 1. 本轮目标

本轮以截图汇报和成果展示为目标，对前端演示系统进行全页面内容补全。前端不依赖真实算法执行，也不要求后端接口始终可用；所有核心页面均具备稳定的演示数据回退，保证页面、菜单、详情和弹窗可直接展示。

真实能力边界保持不变：

- LDD 仍是当前唯一真实接入的训练前数据清洗算法。
- 训练中、训练后算法保留统一架构和方案详情，但不触发真实执行。
- 实验基线保持 `batch_size=128`、`epochs=5`。

## 2. 数据填充问题

### 原问题

- 页面依赖接口返回数据，接口为空或服务未启动时容易出现空表。
- 算法资源只有概要信息，缺少参数、原理和实验结果。
- 任务详情在接口不可用时缺少报告、日志和审计内容。

### 已完成整改

- 新增统一演示数据层 `migration-frontend/src/data/demoData.js`。
- 预置数据集、算法、任务、风险案例和平台活动数据。
- 任务中心增加模拟任务统计、执行池状态、报告、参数快照、日志和操作记录。
- 数据集和算法资源接口无数据时自动回退到结构化样例数据。
- 统计页增加样本处理量、风险等级、隔离比例、攻击成功率和阶段覆盖度数据。

## 3. 模块功能缺失问题

### 原问题

- 只有工作台、资源和任务页面，缺少统计、案例和配置管理等配套模块。
- 三大防御页面只有算法卡片，没有独立的算法详情入口。
- 训练中防御页面原为接口预览，无法支撑正式成果展示。

### 已完成整改

- 新增“数据统计”模块：展示清洗效果、风险分布、阶段能力和指标口径。
- 新增“防御案例”模块：展示典型案例、风险等级、处置流程和案例详情弹窗。
- 将“接口扩展预览”改为“参数配置台账”：展示配置记录、关联任务、参数明细和变更历史。
- 新增算法独立详情页 `/algorithms/:algorithmKey`。
- 算法详情包含算法原理、适用场景、参数配置、运行环境和模拟实验结果。
- 三大防御页面均可进入对应算法详情，训练前 LDD 可继续进入任务中心。

## 4. UI 排版问题

### 原问题

- 工作台信息密度偏低，缺少趋势、风险和动态信息。
- 卡片内容层级不足，截图时难以体现平台业务规模。
- 页面之间缺少统一的数据视觉语言。

### 已完成整改

- 工作台新增实验趋势柱状图、防御体系覆盖、近期任务、平台动态和关键指标。
- 统一统计卡片、标签、表格、详情面板、时间线和参数区域的视觉层级。
- 新增响应式布局，窄屏下统计卡片、详情区域和案例卡片自动单列。
- 登录页调整为正式平台入口，补充平台品牌、能力摘要、运行状态和成果展示入口。
- 统一使用业务化文案，移除“迁移版”“Mock”“Vue 3 + Vite”等开发过程信息。
- 保留 Element Plus 表格、标签、进度、步骤和描述列表组件，保证页面风格一致。

## 5. 表单完善问题

### 原问题

- 数据集和算法表单字段不够完整，新增后信息密度不足。
- 新增功能缺少与业务流程对应的配置内容。

### 已完成整改

- 数据集表单包含名称、类型、样本量、标签数、路径、说明和启用状态。
- 算法表单包含名称、防御阶段、算法类型、分类、描述、实现路径和接入状态。
- 新增案例弹窗包含案例名称、防御阶段和案例说明。
- 新增配置弹窗包含配置名称、关联算法和配置备注。
- 参数详情统一以表格方式展示名称、取值和说明，便于截图和答辩讲解。

## 6. 验证结果

- 前端生产构建通过。
- `/dashboard`、`/datasets`、`/algorithms`、`/tasks` 可访问。
- `/statistics`、`/cases`、`/training-defense` 可访问。
- `/defense/pre`、`/defense/during`、`/defense/post` 均有完整算法内容。
- `/algorithms/ldd` 等算法详情页可访问。
- 登录页不再展示框架迁移或开发技术栈说明，演示入口可直接进入工作台。
- 训练中 `Gradient Shield` 等方案可进入独立详情页，算法名称、参数和指标与演示数据一致。
- 未改动真实 LDD 实验配置和后端执行协议。

## 7. 后续可选优化

- 将演示数据按环境开关拆分为“演示数据”和“接口数据”两套数据源。
- 增加截图专用的全屏展示模式和打印样式。
- 为算法详情页增加 SVG/Canvas 指标趋势图和样本风险分布图。
- 将配置台账、案例库和统计结果进一步接入后端持久化。

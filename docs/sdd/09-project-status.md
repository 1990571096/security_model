# 项目目标与阶段进度说明

更新时间：2026-09-10

本轮工程验证：后端定向测试 32 项全部通过，前端使用独立输出目录完成生产构建，Python 适配器
语法检查均通过。前端仅保留旧版 Vue CLI 依赖产生的资源体积与 Browserslist 警告；
本轮不启动真实 LDD 训练。

## 1. 项目整体目标

本项目由早期网络安全竞赛项目重构而来，目标是形成“面向数据清洗的安全模型训练系统”。系统围绕图像训练数据的后门中毒风险，提供数据集管理、LDD 清洗任务、任务监控、参数快照、实验报告和清洗子集导出能力。

当前阶段只开放 LDD 训练前数据清洗。其他训练前对比算法、训练中防御和训练后防御仅保留扩展边界，不属于当前展示范围。

## 2. 当前技术基线

当前运行基座仍为 Spring Boot 2.7 + Vue 2 + MySQL + Redis + Python。Spring Boot 3、Java 17、Vue 3、Vite、Element Plus 和 Pinia 是后续目标技术栈。

当前不立即迁移框架，原因是 LDD 执行链路、任务协议和页面展示刚完成收敛。先冻结业务边界和接口，再进行框架升级，能够减少业务重写与框架迁移叠加造成的返工。

## 3. 当前业务流程

```text
登记图像数据集
  -> 选择 LDD 和超参数
  -> 创建训练前清洗任务
  -> 校验资源和参数
  -> 生成执行参数快照
  -> 调用 VaB LDD
  -> 保存索引、图像、日志和结构化结果
  -> 查看进度和实验报告
  -> 按保留索引导出清洗后的 CIFAR-10 子集
```

| 执行日志 | 支持从任务结果登记的日志文件中安全读取内容；运行中的任务会轮询当前尝试目录下的标准输出和错误输出，并按 offset 增量读取。 |

| 清洗子集导出 | 根据 LDD 输出的 `selected_indices_<ratio>.npy` 异步重建 CIFAR-10 清洗子集，支持进度、失败重试、应用重启恢复和 ZIP 下载。 |
| 工程验证 | 已完成一次 CIFAR-10 / SIG / batch size 128 / 5 epochs 的 LDD 工程验证；不等同于论文正式实验。 |
| 任务工程约束 | 已增加任务名称搜索、非 pending 任务编辑保护、状态/进度范围校验、批量请求规模与空值校验、run_id/attempt 标识和重试目录隔离。 |
| 并发与事务一致性 | 已使用数据库条件更新保护任务领取；旧运行回调按 run_id 丢弃；外部执行器在事务提交后派发；线程池拒绝会收敛为可重试失败。 |
| 导出并发幂等 | 已通过 `(task_id, isolation_ratio)` 唯一键和原子插入保证并发提交只创建一条导出任务并只调度一次。 |
| 配置治理 | 已按“算法默认配置 -> 超参数模板 -> 任务自定义参数”合并，并对 LDD 白名单、类型、范围和必填项校验。 |
| 产物安全 | 已对 PNG、日志、索引和异步 ZIP 执行真实路径 containment 校验，避免符号链接绕出任务产物目录。 |
| 应用重启恢复 | 已将无法恢复的训练和导出运行任务收敛为可解释失败，并重新派发启动时遗留的 pending 导出任务。 |
| 资源生命周期 | 已阻止删除仍被任务引用的数据集、算法和超参数模板，避免历史报告与导出链路失去依赖。 |

## 5. 当前可演示能力

- 登录后进入安全训练工作台。
- 查看和维护图像数据集。
- 在算法库中查看 LDD 配置。
- 创建 LDD 训练前数据清洗任务。
- 配置批次大小、训练轮数、攻击方式和清洗参数。
- 启动任务并查看运行进度。
- 查看失败原因并执行失败任务重试。
- 查看某次执行的参数快照和 LDD 实验报告。
- 预览任务产物中的 PNG 图像。
- 按隔离比例提交导出任务，查看导出进度并下载由保留索引重建的 CIFAR-10 清洗子集。

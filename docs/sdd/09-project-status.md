# 项目目标与阶段进度说明

更新时间：2026-08-29

本轮工程验证：后端 `mvn -pl eladmin-system -am compile '-Denforcer.skip=true'`、
前端 `npm run build:prod` 和 Python 适配器语法检查均通过。前端仅保留旧版 Vue CLI
依赖产生的资源体积与 Browserslist 警告；本轮未启动真实 LDD 训练。

## 1. 项目整体目标

本项目由早期网络安全竞赛项目重构而来，目标是形成“面向数据清洗的安全模型训练系统”。系统围绕图像训练数据的后门中毒风险，提供数据集管理、LDD 清洗任务、任务监控、参数快照、实验报告和清洗子集导出能力。

当前阶段只开放 LDD 训练前数据清洗。其他训练前对比算法、训练中防御和训练后防御仅保留扩展边界，不属于当前展示范围。

## 2. 当前技术基线

当前运行基座仍为 Spring Boot 2.7 + Vue 2 + MySQL + Redis + Python。Spring Boot 3、Java 17、Vue 3、Vite、Element Plus 和 Pinia 是后续目标技术栈。

当前不立即迁移框架，原因是 LDD 执行链路、任务协议和页面展示刚完成收敛。先冻结业务边界和接口，再进行框架升级，能够减少业务重写与框架迁移叠加造成的返工。

## 3. 当前业务流程

```text
登记图像数据集
  -> 选择 LDD 和超参数
  -> 创建训练前清洗任务
  -> 校验资源和参数
  -> 生成执行参数快照
  -> 调用 VaB LDD
  -> 保存索引、图像、日志和结构化结果
  -> 查看进度和实验报告
  -> 按保留索引导出清洗后的 CIFAR-10 子集
```

## 5. 当前可演示能力

- 登录后进入安全训练工作台。
- 查看和维护图像数据集。
- 在算法库中查看 LDD 配置。
- 创建 LDD 训练前数据清洗任务。
- 配置批次大小、训练轮数、攻击方式和清洗参数。
- 启动任务并查看运行进度。
- 查看失败原因并执行失败任务重试。
- 查看某次执行的参数快照和 LDD 实验报告。
- 预览任务产物中的 PNG 图像。
- 按隔离比例下载由保留索引重建的 CIFAR-10 清洗子集。

## 6. 待完成与优化建议

### P0：正式实验闭环

1. 根据论文实验方案确定正式数据集、攻击设置、训练轮次和 LDD 参数。
2. 固化实验配置和数据版本，执行正式实验并保存结果。
3. 确认论文指标定义，补齐清洗率、攻击成功率、干净准确率和性能保持率等指标。

### P1：平台工程完善

1. 增加实时日志展示。
2. 完善后端参数 schema 校验，包括类型、必填项、范围和参数间约束。
3. 增加任务超时、取消和异常进程回收能力。
4. 将清洗子集导出改为异步导出任务，避免大文件下载占用请求线程。
5. 增加“清洗后数据集 -> 后续模型训练”衔接入口，但暂不接入训练中防御算法。

### P2：框架迁移与裁剪

1. 先裁剪无关 ELADMIN 模块和依赖，保留当前 LDD 业务接口。
2. 后端迁移到 Java 17 + Spring Boot 3。
3. 前端迁移到 Vue 3 + Vite + Element Plus + Pinia。
4. 迁移完成后执行登录、权限、数据集、LDD 任务和报告页面回归。

## 7. 明确暂不做

- 当前不接入 VS、MetaPurifier 或其他对比算法。
- 当前不接入训练中防御和训练后防御。
- 当前不把 mock baseline 作为展示功能。
- 当前不以工程验证结果替代论文正式实验结论。

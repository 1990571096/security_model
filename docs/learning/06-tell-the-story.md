# 06 做一次模拟面试

打开自己的 [任务追踪工作表](task-notebook.md)，用第 01 课真正看过的请求或源码模拟记录做例子。

1. 定时 90 秒。按实验者目标、建档、启动、Python、结果和导出顺序讲完。
2. 画 3 分钟白板。给 HTTP、MySQL 和 Python 文件三条边分别写出一个真实方法名或文件名。
3. 让听众选一个中断点。可以问“Java 已经提交 SQL 但进程还没启动”或“Python 写出结果时任务已经取消”。先讲该点前已经落下的证据，再说恢复、拒绝或终态更新。
4. 录音后听一遍。标出只说了技术名字的位置，每处换成这个项目确实做的一次读写。

**卡壳时用这段起步**

> 实验者想筛出可用于后续训练的数据。页面先建一条待运行任务，用户核对后确认启动。后端领取任务并保存这一轮的配置与派发意图。执行时 Java 先写请求文件，通过命令参数把路径交给 Python。Python 写出进度和结果，Java 核对本轮身份后更新 MySQL，用户从任务详情查看报告。具备真实筛选索引的 CIFAR-10 任务还可以提交子集导出。

收尾用自己实际观察到的证据。面试官问“你主要做了哪部分”时，从亲自实现或验证的内容里选一个例子，说明需求、具体修改、测试和限制。

每项给自己一分。分数低于四分时，按缺项返回练习。

| 得分项 | 达标表现 | 回到哪课 |
| --- | --- | --- |
| 用户目标 | 30 秒内讲清输入、清洗目标和输出 | [贯穿案例](00-one-experiment.md) |
| 正常流程 | 说出两次点击、两个 POST、各自写入 | [页面到数据库](01-follow-a-task.md) |

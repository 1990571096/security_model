# 简历项目参考

**面向训练数据清洗的安全模型实验平台**

基于 Spring Boot、Vue 3、MySQL 和 Python 构建单机实验平台，实现训练前 LDD 任务配置、异步执行、结果报告和 CIFAR-10 清洗子集导出。可按部署配置使用进程内派发或 RabbitMQ 独立 Worker。

- **算法接入**。通过 `DefenseTaskExecutor` 封装 LDD 执行，使用 `ProcessBuilder` 启动 Python 适配器，按运行轮次保存请求、进度、日志与结果并校验回写身份。
- **任务一致性**。使用事务内调度意图、请求幂等、SQL 条件更新与 `runId` 处理网络重发、并发领取和旧执行结果。结合进程树检查与 GPU 单槽租约收敛取消、超时和恢复。
- **可选消息派发**。在启动事务内写入 Outbox，使用 Relay 发布确认、Worker 领取与手动 ACK，配合 MySQL 消费账本处理重复投递。
- **实验追溯**。记录执行快照、资源指纹与 Python 运行环境，提供增量日志、权限校验、产物报告和独立导出任务。
- **知识与助手**。从独立共享知识库检索带行号的引用，按任务归属和当前尝试读取证据，诊断实验失败。

从实际负责的工作中选三条。训练算法范围写“训练前 LDD”。论文指标与生产级交付需有各自的证据。各次测试数字和运行范围见 [验收记录](sdd/26-current-delivery-facts.md)。

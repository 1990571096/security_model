# 实验失败排查

## 执行器未配置

看到 `EXECUTOR_NOT_CONFIGURED` 时，核对实际执行任务的进程是否已配置执行器。数据库派发模式由 API 进程负责执行，消息队列模式由 Worker 执行。可请管理员核对对应进程的配置与运行账号权限。

## GPU 显存不足

看到 `GPU_OOM` 时，先区分设备显存与系统内存，检查失败时的 GPU 显存及其占用进程。保存本次运行的资源记录，再决定是否需要调整实验计划。

## 派发和结果缺失

派发被执行器接受，只能确认交接状态。检查任务的当前运行记录和日志，确认进程是否启动。遇到 `RESULT_MISSING` 或协议错误时，核对报告中的错误码和结果文件生成状态。
